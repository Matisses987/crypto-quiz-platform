# 密码赛刷题平台 · 使用说明

> 适用对象：2026 年江苏省密码行业职业技能竞赛 · 学生组（以及任何要刷这套理论题库的同学）
> 成品文件：`dist/密码赛刷题平台.html`（单文件，双击即用）
> 版本：**应用版本 1.1.0**（题库 / 存储 / 导出 schema 版本仍为 **1.0.0**——队友用旧版导出的 JSON 与你的旧本地数据都能继续导入 / 加载）

---

## 0. 一句话了解

一个**离线单文件**刷题平台：1051 道理论题（1050 道打印题号 + 1 道未编号题，全部自带答案），按「部分 → 章 → 题型 + 知识点标签」分类，支持分类练习 / 全库随机 / 错题本 / 三色信心标记 / 学习统计与掌握指数 / 按自然日导出与导入汇总 / 100 题 60 分钟模拟选拔赛 / 标疑问与手动改答案。

**不需要安装、不需要联网、不需要服务器**；所有数据只保存在你这台电脑的浏览器里。

---

## 1. 如何打开

1. 找到 `dist/密码赛刷题平台.html`；
2. **双击**它（或右键 →「打开方式」→ Chrome / Edge）；
3. 地址栏会显示 `file:///…/密码赛刷题平台.html`，看到「今日学习」页面即成功。

注意事项：

- 推荐 **Chrome / Edge** 最新版；Firefox 亦可。屏幕以 1024px 以上宽度体验最佳，窄屏可横向滚动。
- 首次进入会弹窗要求**填昵称**（1–20 字）。昵称用于导出文件与团队统计归属；之后可在首页「修改昵称」更改（改昵称**不会**改变历史记录归属）。
- 数据存在**本机浏览器**（`localStorage`），不联网、不上传。换浏览器、换电脑、清缓存、无痕窗口都会看不到旧数据 —— **请定期导出备份**（见第 10 节）。
- 若顶部出现红色横幅「本地存储不可用，数据无法保存，请立即导出备份」，说明浏览器禁用了本地存储：本次仍可答题，但刷新即丢。

## 2. 练题入口

首页「快速开始」有 8 个入口：分类练习、全库随机、错题本、学习统计、团队对比、导出/导入、模拟选拔赛、校对纠错。顶部导航栏随时可切换。

### 2.1 分类练习（按三级结构 + 知识点标签）

在「分类练习」页：

1. 模式保持「分类练习」；
2. 左侧「三级结构」树：**基础题 / 专业题**（可勾选）→ **章**（可勾选）→ 章内显示 **题型**（单选/多选/判断/填空）与「全库单选题/多选题…」勾选框；
   - 每章/每题型后面括号里是「共 N 题，已练 M」；
   - **不勾选任何层级 = 全部参与**；勾选「部分」后只在该部分内出题，与已勾选的章、题型取交集；
   - 若选择组合没有题目，右侧显示「命中 0 题」且「开始答题」按钮置灰。
3. 右侧「知识点标签」：点击任意标签（可多选，命中**任一**标签即入选）；标签后数字是该标签命中题数；「清空标签」取消全部；
4. 「题量」默认 20（1…1051 可改）；
5. 右侧徽标实时显示「命中 N 题」；点「开始答题」进入答题页。

### 2.2 全库随机

同样在「分类练习」页，把模式切到「全库随机（1051 题）」——树与标签会隐藏，直接从全部可答题目随机抽题。

两种模式都是：**随机抽题、同一轮内不重复、题量可指定**。

## 3. 答题、判分与计分

答题页顶部显示「第 n / N 题」「已答 x 题」、进度条，以及 **上一题 / 跳过 / 交卷 / 下一题** 按钮。

各题型的作答方式：

| 题型 | 控件 | 判分规则 |
| --- | --- | --- |
| 单选题 | 单选按钮 | 必须选对 |
| 多选题 | 复选框 | **全对才算对**（漏选、多选、少选一律判错） |
| 判断题 | 对 / 错 | 只能选「对」或「错」 |
| 填空题 | 文本框 | 忽略**大小写**与**首尾空格**；全角字符按半角判分（如 `ＳＭ４` = `SM4`）；支持一题多个可接受答案（在「校对纠错」里补录） |

点「提交」后**立即**判分：

- 选项着色：正确项绿色、你选错的项红色；
- 显示「回答正确 / 回答错误」与**正确答案**；
- 出现信心按钮（见第 4 节）；
- **提交即保存**：这一题的作答记录此刻已写入本地存储，此时直接点导航/刷新/关页面也不会丢（也不会重复计数）。

「跳过」= 本题记为未作答、不写记录、不计入掌握指数；本轮结算会显示未作答数。

本轮最后一题点「交卷并结算」（或随时点「交卷」，二次确认）进入结算页：得分「正确 X / 共 N」、正确率、未作答数，以及**逐题三色明细**（绿・有把握对 / 黄・猜对 / 红・错）和每题是否进入错题本。

---

## 4. 信心按钮与三色规则（重点）

模拟的是真考心态：会做就标「有把握」，蒙的就标「带猜测」。

- **信心标记在提交后立即选择**，默认「有把握」，**进入下一题之前可以随时回改**（回改会立刻更新颜色、错题本与统计）；
- 颜色由「答对/答错 + 信心」决定：

| 情况 | 颜色 | 是否进错题本 | 掌握指数权重 |
| --- | --- | --- | --- |
| 答对 + 有把握 | 🟢 绿 | **不进** | ×1.0 |
| 答对 + 带猜测（猜对） | 🟡 黄 | **进** | ×0.5 |
| 答错（无论信心） | 🔴 红 | **进** | ×0 |

## 5. 错题本

「错题本」页：

- 列表列：颜色来源、题目（题干摘要 + 题号 + 章 + 题型 + 已标疑问角标）、**错过次数**、对过次数、猜对次数、**掌握指数**、状态、操作；
- 筛选：**状态**（在册 / 已移出 / 全部）、**章**、**题型**、**颜色**（红・答错 / 黄・猜对 / 绿・已移出）、**知识点**；
- 「错题重练（N 题）」：把在册错题全部抽出来重练；每行还有「练一题」只练该题；
- 「移出」：手动移出错题本（**不会**删除作答记录，统计仍包含该次作答）；
- 自动移出：在册错题**连续 2 次「有把握答对」**会自动移出，状态列显示「已自动移出（连续 2 次有把握答对）」；中途一旦答错或标了「带猜测」，连续计数归零；
- 已移出的题在「状态=已移出」里查看，点「重新加入」可再放回错题本（该题若再次答错或猜对，也会自动重新进入）。

## 6. 学习统计与掌握指数

「学习统计」页顶部可选日期范围（**单日 / 全部 / 区间**，日期用日历控件选择）与统计对象（导入队友数据后可切换昵称）。

- **总览**：范围内作答数、正确数、正确率、范围内掌握指数；累计作答数、累计正确率、累计掌握指数、个人易错题数；
- **分章 / 分题型**表：题量、作答、正确率、掌握指数；**表头可点击排序**（▲ 升序 / ▼ 降序，再点一次切换）；
- **薄弱知识点 TOP**：按知识点统计正确率，从低到高（作答 ≥3 次才上榜）；
- **薄弱题目 TOP**：掌握指数最低的题目；
- **每题明细**：题号、章、题型、题干、作答次数、对、**有把握对**、错、猜对、掌握指数；默认显示前 60 题可「显示更多」；右上「去导出 / 导入」直达导出页。

**掌握指数**（0–100）：

```
单题：index = (有把握答对 × 1 + 猜对 × 0.5 + 答错 × 0) ÷ 作答次数 × 100   （保留 1 位小数）
全局：把所有题的分子相加 ÷ 所有题的作答次数之和 × 100（加权平均，不是各题指数求平均）
```

**样本不足**：某题（或某组）作答次数少于 3 次时显示「样本不足」而不显示数值，避免次数太少导致指数虚高/虚低。

## 7. 按某一天导出（学习情况 JSON）

「导出 / 导入」页 →「导出学习情况（按本地自然日）」：

1. 选范围：**单日 / 区间 / 全部**；
2. 选日期（`单日` 用第一个日期框；`区间` 用起止两个日期框；默认今天）；
   - 若起始日期晚于结束日期，页面提示「起始日期不能晚于结束日期」且导出按钮置灰；
3. 页面会显示本次将导出的条数（作答记录 / 模拟赛场次 / 纠错覆盖层）与**文件名预览**；
4. 点「导出」→ 浏览器下载 JSON 文件，文件名形如
   `密码赛学习记录_小明_单日2026-10-06_20261006-223015.json`。

导出文件包含：**应用版本（`appVersion` = `1.1.0`）与数据格式版本（`schemaVersion` = `1.0.0`）**、题库版本（`2026.08-pdf1`）、导出时刻、**昵称**、日期范围、逐条作答记录（题号、作答、对错、信心、颜色、用时、时间戳、本地自然日）、模拟赛记录、以及**纠错覆盖层（标疑问与手动改答案，整体导出、不按日期裁剪）**。

> 兼容性：数据格式版本（schema）保持 `1.0.0` 不变，所以**旧版本（应用 1.0.0）导出的文件仍可正常导入**，你的旧本地数据也会被自动读取并继续使用；`appVersion` 只记录「这份记录是哪个程序版本写下的」，不参与兼容性判定（导入只校验 schema 主版本号 `1`）。

> 日期口径 = **本地自然日**。晚上 23:59 交的卷算当天，第二天凌晨 00:10 的练习算第二天。

## 8. 团队汇总：导入队友的文件

1. 队友各自在自己电脑上按第 7 节导出，把 JSON 发给你（微信/QQ/邮件均可，文件很小）；
2. 你在「导出 / 导入」页 →「导入队友记录」→ 选择文件；
3. 页面先给出**校验结果**：合法则显示文件里的记录数、模拟赛场次、覆盖层条数与导出人昵称，点「**确认合并**」才会写入；非法则给出原因（如「文件不是合法 JSON」「不是本平台的导出文件」「数据版本不兼容」「文件已损坏（计数不一致）」），**本地数据保持不变**；
4. 合并规则：按「昵称 + 题号 + 时间戳」去重 —— **同一个文件导入多少次，统计结果都一样**；重复导入会提示「本次导入 0 条新增记录，N 条为重复记录（未重复计数）」；坏记录会被跳过并在报告中列出原因，未知题号不会入库；
5. 「导入历史」台账记录每次导入的文件名、时间、昵称、新增/重复/跳过条数。

### 查看团队与个人易错题

在「团队对比」页：

- **成员对比表**：每个昵称一行 —— 作答数、正确数、正确率、掌握指数（样本不足会标注）、个人易错题数、模拟赛最高分；
- **团队易错题（≥2 人答错）**：按「答错人数」降序 —— 列有答错人数、答错总次数、错误率、团队掌握指数、答错成员名单；
- **个人易错题**：右上角可切换昵称，列出该成员判错过至少 1 次的题（错过次数、对过次数、猜对次数、掌握指数），按错过次数排序；
- **交叉矩阵**：行 = 团队易错题，列 = 成员，单元格显示 对 / 错 / 猜对 / 未做。

> 团队 = 本机昵称 + 所有已导入文件里的昵称；同一昵称视为同一个人（含换设备的情况）。

## 9. 标疑问与手动改答案（校对纠错）

题库来自 PDF 解析，个别题可能有排版问题。在「校对纠错」页可以自己修：

- 筛选：**已标疑问 / 待校对（题库缺陷）/ 已改答案 / 全部题目**，另可按章筛选、按题干或题号搜索；
- 每题显示：题号、章、题型、打印题号、当前答案、题干、选项；
- 操作：
  - **改答案**：输入框填答案。选择题写字母（如 `ABD`，也可 `A,B,D`）；填空/判断用逗号分隔多个可接受答案（如 `SM4,SM4算法`、或 `16 块`）；
  - **标疑问**：勾选后该题在题目卡上显示「已标疑问」角标（不影响出题，只是提醒自己待确认）；
  - **备注**：最多 200 字；
  - **保存** → 立即生效（后续判分、正确答案展示都用新答案）；
  - **恢复原值** → 撤销手动答案，回到题库原答案（标疑问保留）；
- 覆盖层会**随导出文件共享**：队友导入你的文件后自动生效（同一题按最后修改时间取胜，时间相同按昵称字典序）。

答题页也有「标疑问」与「去校对改答案」按钮，方便遇到可疑题目时就地处理。

## 10. 备份、清空与数据安全

- **备份**：首页「导出全部备份」（或校对页危险操作区的同名按钮）会把本机全部记录 + 错题本以外的一切（作答记录、模拟赛、覆盖层）导出为一个 JSON。建议每周、以及每次导入队友数据前后各导一次。
- **原始存储排查**：「校对纠错」页 → 危险操作区 →「导出原始存储内容」，用于排查数据异常（例如提示 JSON 解析失败时）。
- **清空数据**：「校对纠错」页 → 危险操作区 →「清空本地数据（二次确认）」，会删除本机全部作答记录、错题本、纠错覆盖层、模拟赛记录与导入台账，**不可恢复**。清空前务必先导出备份。
- **再次提醒**：数据只存在于**当前浏览器的本地存储**里，不会自动同步；换电脑/换浏览器/无痕模式/清缓存都会丢失。

## 11. 模拟选拔赛（100 题 / 60 分钟 / 100 分）

点「模拟选拔赛」→ 确认页写明题量 100、限时 60 分钟、满分 100（每题 1 分）、到点自动交卷 →「开始答题」。

答题期（对齐官方赛制）：

- 右上角 **60:00 倒计时**，剩余 ≤5 分钟变红；**到 0 自动交卷**（以提交时作答情况为准）；
- 左侧 **题号面板**：蓝=已答、黄=已标记、深色=当前题，点题号可跳题；「标记待回看」只影响你自己的复习标记；
- **不显示对错、不显示正确答案、不提供信心选择**（避免泄露答案）；
- 交卷需二次确认；中途切走页面会提示本次成绩作废（已答题目仍会保存为作答记录，计入统计）。

交卷后：

- 总分（答对题数）、答对、未作答、总用时；
- **分项成绩固定按「填空 → 多选 → 单选 → 判断」** 给出得分/题数/用时（对齐官方同分排名细则）；
- 排序键 rankKey = [总分, -总用时(毫秒), 填空得分, 多选得分, 单选得分, 判断得分]；
- 本次抽题分布（题型与章的实际抽题数）；
- 「把本次错题加入错题本」一键补录（模拟赛默认不自动写错题本）；
- **全部 100 题（逐题改信心）**：给答对的题标「带猜测」→ 颜色变黄、按三色规则进入错题本、掌握指数改为 ×0.5；再改回「有把握」→ 撤回本次计入并出册；已在错题本的题按「连续 2 次有把握答对自动移出」规则更新。

抽题分布（按题库池占比两级最大余数法）：填空 3 / 多选 34 / 单选 47 / 判断 16；章分布 C01 6、C02 5、C03 5、C04 4、C05 37、C06 19、C07 24。

## 13. 常见问题

**Q：多选题少选一个算对一半分吗？**
不算。多选题**全对才算对**。

**Q：填空题我输入的是全角字符或者大小写不一样，会不会判错？**
不会。判分前会做全角→半角折叠、去首尾空格、忽略大小写。但**内部空格不忽略**（`SM 4` ≠ `SM4`），也不做同义替换（`256位` ≠ `256`）；这类情况请在「校对纠错」里给该题补多答案。

**Q：题目数量到底是 1050 还是 1051？**
按 PDF 打印题号是 **1050** 题；平台内共有 **1051** 个题块 —— 多出来的 1 道是 PDF 第 52 页那道**没有编号**的题（应用内标注「未编号题」）。两种口径在「数据与题库」卡片里都能看到。

**Q：有些题带着「待校对」角标是什么意思？**
题库解析时发现的 5 道特殊题（未编号题、原本缺答案的题、题型与答案形状不一致的题等）。它们可以正常作答，标角标是提醒你留意；缺答案的题解析阶段已按题库原文补录（如第 97 页填空题为 `16`）。

**Q：导入队友文件后我的数据会不会被覆盖？**
不会。导入是**只增不改**：本地已有记录永不被覆盖，重复记录按去重键跳过；纠错覆盖层按修改时间取胜（最后修改的生效）。

**Q：为什么统计里显示「样本不足」？**
该题/该组作答次数少于 3 次。多练几次就会出现数值。

**Q：换了电脑还能看到我的记录吗？**
不能自动同步。请把导出的 JSON 在新电脑上「导入」回来（昵称相同即视为同一个人，记录会合并）。

**Q：打开后顶部出现红色横幅「数据版本不兼容…」或「本地数据损坏…」怎么办？数据还在吗？**
**数据还在**，只是当前这版程序读不懂它。这时平台会自动进入**只读抢救模式**：
1. 本次运行**不会写入任何数据，也不会清空**任何数据（刷新、关闭标签页都不会动你的数据）；
2. 去「导出 / 导入」页，会看到「只读抢救模式」卡片，显示浏览器里**磁盘上的**昵称、作答记录数、模拟赛场次、纠错覆盖层与检测到的数据版本；
3. 点「**导出抢救备份（读取原始数据）**」把数据取出来 —— 它是**直接读浏览器里的原始内容**生成的（不是空备份）；若有个别内容连 JSON 都解析不了，会以**原始字符串**一并放进导出文件（`rescue.rawKeys`），便于手工抢救；
4. 恢复用的正确姿势：把这份抢救备份留好，用**对应版本**的程序（或修复后的新版本）导入回去；在问题解决前不要清空浏览器数据。

> 只有「能读到数据但版本不兼容/内容损坏」时才会出现这个模式。正常使用时（包括答错、错题本、模拟赛）行为完全不变：提交即落库、卸载兜底照写。
