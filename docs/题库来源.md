# 题库来源与版权说明

## 来源

本项目的题库数据（`src/data/bank.json`）由**竞赛组委会公开发布的题库文件**（PDF，199 页）解析而来：理论题 1050 道（另有 1 道未编号题），题型含单选 / 多选 / 判断 / 填空，全部自带答案。原文件由组委会在江苏省密码管理局网站公布，**版权归竞赛组委会所有**。

## 本仓库有什么、没有什么

- **有**：解析后的结构化数据（`src/data/bank.json` 与 `bank.report.json`）、解析报告（`docs/解析报告.md`）、解析与构建工具（`tools/`）；
- **没有**：组委会发布的原始题库文件本身（本仓库不转载原始 PDF），也没有任何个人材料。

## 免责与联系

- 本项目是**个人备赛工具**，不是官方发布物；
- 题库内容版权归竞赛组委会。若版权方认为本仓库内容不妥，请在仓库提 Issue 联系，我会第一时间删除相关内容；
- 想自行重建数据：把组委会发布的题库 PDF 放到仓库根目录，然后运行
  `python tools/parse_bank.py --pdf <你的文件.pdf>`（见 `README.md`「从源码重建」）。

## 数据格式

题块 schema 与冻结口径见 [`docs/需求规格.md`](需求规格.md) 第 5 章；逐项解析处理与已知缺陷说明见 [`docs/解析报告.md`](解析报告.md)。
