# 密码赛刷题平台

面向 **2026 年江苏省密码行业职业技能竞赛（学生组）** 理论备赛的**离线刷题工具**：一个自包含的单文件网页，双击即用 —— 无需安装、无需联网、无任何外链、零第三方依赖。

- **题库**：1051 个题块（1050 道印刷题号 + 1 道未编号题），题型含单选 / 多选 / 判断 / 填空，全部自带答案；
- **分类**：部分 → 章 → 题型三级结构，另加知识点标签；
- **数据**：只保存在使用者本机浏览器（`localStorage`），靠导出 / 导入 JSON 做备份与团队汇总。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动分类 | 按「部分 → 章 → 题型」三级结构 + 知识点标签筛选 |
| 分类练习 / 全库随机 | 两种模式随机出题，提交即批改、即落库 |
| 自动批改与计分 | 单选 / 判断精确匹配；多选**全对才算对**；填空忽略大小写、首尾空格与全角半角差异，支持多答案 |
| 三色信心标记 | 提交后立即标记「有把握 / 带猜测」：错 = 红（进错题本）、猜对 = 黄（进错题本）、有把握且对 = 绿（不进） |
| 错题本 | 自动进出（连续 2 次「有把握答对」自动移出）+ 手动移出；在册 / 已移出视图 |
| 学习统计 | 每题对 / 错次数 + 掌握指数 =（有把握对×1 + 猜对×0.5 + 错×0）÷ 作答次数 × 100，样本 < 3 显示「样本不足」 |
| 按日导出 / 团队汇总 | 按本地自然日 / 区间 / 全部导出 JSON；导入队友文件后统计团队易错题（≥2 人答错）、个人易错题与交叉矩阵 |
| 模拟选拔赛 | 100 题 / 60 分钟 / 100 分 / 到点自动交卷；成绩页可逐题改信心 |
| 校对纠错 | 标疑问与手动改答案（修正可随导出共享） |

## 快速开始

1. 下载 `dist/密码赛刷题平台.html`（或直接打开 GitHub Pages 上的 `index.html`）；
2. 双击它（推荐 Chrome / Edge），地址栏会是 `file:///…`；
3. 首次进入填昵称，然后开始刷题；数据只存在本机浏览器，随时用「导出全部备份」留底。

更细的操作说明（三色规则、错题本进出、掌握指数、按日导出、团队汇总、备份与清空）见 [`docs/使用说明.md`](docs/使用说明.md)。

## 从源码重建

需要 Node.js ≥ 18；若要从 PDF 重新解析题库，另需 Python 3 与 `pypdfium2`。

```bash
# ① 解析题库（把组委会发布的题库 PDF 放到仓库根目录，或改 --pdf 路径）
python tools/parse_bank.py --pdf 题库.pdf

# ② 校验题库结构（冻结契约全项，退出码 0 即通过）
node tools/validate_bank.mjs

# ③ 跑回归测试
node --test tests/

# ④ 构建单文件成品 -> dist/密码赛刷题平台.html
node tools/build.mjs
```

## 技术说明

- **单文件自包含**：HTML / CSS / JS / 题库 JSON 全部内联进一个文件，外部引用 0、网络请求 0；
- **零依赖**：无框架、无构建依赖、无 CDN；核心逻辑是可直接 `import` 的 ES module，测试用 Node 内置 `node:test`；
- **数据只存本地**：作答记录只写在浏览器 `localStorage`（键前缀 `cqp.v1.`），不上传任何服务器；团队汇总靠手动导出 / 导入 JSON；
- **可复现构建**：同一份源码与题库数据重复构建，产物一致。

## 已知限制

1. 模拟赛成绩页对「已被手动移出」的题仍显示「已在错题本」角标（**仅显示层**，不影响错题本状态与统计）；
2. 界面没有「继续练习」入口：中途离开练习轮后需要重新进入（作答状态本身不会丢）；
3. 知识点词表未完全扩充：部分题目只有章级兜底标签，标签筛选粒度较粗（出题 / 判分 / 统计不受影响）；
4. 题库文本层保留了少量行内空格（保留 PDF 原文口径，不影响判分、统计与导出）；
5. 尚未由人工在 Chrome / Edge 真机上逐项走查（自动化测试与无头浏览器冒烟已覆盖主流程）。
